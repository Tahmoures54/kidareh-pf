# کیدارِه: دسته‌بندی‌ها، اصناف و مکان‌های ایران

## دسته‌بندی کالا و خدمات
فهرست دسته‌بندی‌ها از پروژهٔ قبلی کیدارِه منتقل شده است: **۲۰ گروه اصلی و ۲۷۱ زیر‌دسته**. شناسه‌های قدیمی مثل `home`، `digital` و `vehicle` نیز برای سازگاری با آگهی‌های موجود معتبر می‌مانند.

## اصناف فروشگاه‌ها
فهرست صنف‌ها شامل **۱۱ گروه و ۱۵۷ عنوان صنفی** است. انتخاب صنف فروشگاه اختیاری است و در پروفایل ویترین ذخیره می‌شود.

## تقسیمات کشوری
دادهٔ نسخه‌بندی‌شده شامل استان‌ها، شهرستان‌ها، بخش‌ها، دهستان‌ها و **۱٬۴۸۱ شهر** است. منبع داده، پروژهٔ [list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran) و فایل‌های تقسیمات کشوری تا سال ۱۴۰۴ است.

برای جلوگیری از افزودن یک فایل JSON بسیار بزرگ به تاریخچهٔ Git، فهرست **۹۹٬۳۱۷ آبادی/روستا** هنگام استقرار از نسخهٔ مشخص‌شدهٔ منبع دریافت، اعتبارسنجی و به فایل فشرده تبدیل می‌شود. مسیر تولیدی `kidareh/data/iran-villages-data.json.gz` فقط در محیط ساخت استقرار ایجاد می‌شود؛ بنابراین داده در بستهٔ استقرار قرار می‌گیرد، اما در تاریخچهٔ Git کپی نمی‌شود. اگر منبع در دسترس نباشد یا تعداد رکوردها ناقص باشد، مرحلهٔ آماده‌سازی عمداً شکست می‌خورد تا نسخهٔ ناقص منتشر نشود.

API جست‌وجوی مکان: `GET /api/locations?q=...`؛ برای محدودکردن نتایج می‌توان از `kind=city` یا `kind=village` استفاده کرد. پاسخ فقط پیشنهادهای محدود را برمی‌گرداند، نه کل فهرست را برای هر بازدیدکننده.

## فلسفهٔ بازار
این فهرست‌ها برای یافتن کالا و کسب‌وکار محلی هستند. کیدارِه همچنان بر خرید حضوری در همان محل تمرکز دارد و سبد خرید، پرداخت آنلاین و ارسال کالا به آن اضافه نمی‌کند.
